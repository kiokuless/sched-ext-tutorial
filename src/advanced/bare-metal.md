# 実機で評価する

VM で測った遅延や throughput の絶対値には、ゲスト内のスケジューラだけでなく、ホスト側の実行待ちも混ざる。
VM 上の4 vCPU は物理 CPU コアそのものではなく、ホストのスケジューラが割り当てる実行単位だからである。
本編のように同じ負荷でスライスの影響を比べられても、測定値をそのまま実機の性能とは見なせない。

キャッシュの共有関係、NUMA、SMT、CPU 周波数や電力の影響を調べるには、実際のハードウェア構成に対応した条件が必要になる。
これらを評価する場合は、再起動可能な Linux 実機を使う。
結果を比較できるよう、次の条件を記録する。

- CPU とメモリの構成
- kernel、firmware、scx の版
- CPU governor と SMT の状態
- バックグラウンドサービス
- workload の CPU affinity
- warm-up、試行時間、反復回数
