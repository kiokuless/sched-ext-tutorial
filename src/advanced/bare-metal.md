# 実機で評価する

本編の VM 実験で確かめられたのは、固定した環境内で方針を変えると観測値が動くという因果関係である。
絶対値は環境に依存する。
VM 上の4 vCPUは物理 CPU コアそのものではなく、ホスト scheduler が割り当てる実行単位である。
そのため、LLC、NUMA、SMT、CPU 周波数、電力、対話応答性といった、物理構成に由来する差は VM では観測できない。

これらを評価する場合は、再起動可能な Linux 実機を使う。
その場合も、次の条件を記録する。

- CPU とメモリの構成
- kernel、firmware、`scx` の版
- CPU governor と SMT の状態
- バックグラウンドサービス
- workload の CPU affinity
- warm-up、試行時間、反復回数

VM で得た絶対値を実機の予測値として使わない。
VM の結果が示したのは因果関係である。
環境を固定し、方針だけを変えて比較する、という本編の実験の作法は、実機でもそのまま使う。
